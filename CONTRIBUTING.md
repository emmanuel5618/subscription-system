# Contributing

## Rules

1. Every task starts from a GitHub Issue.
2. Use short-lived branches.
3. Open a pull request early.
4. CI must pass.
5. Another partner must review.
6. Squash merge into main.
7. Do not use float math for money.
8. Do not bypass permissions.
9. Do not edit applied migrations.
10. Documentation must be updated when domain behavior changes.
